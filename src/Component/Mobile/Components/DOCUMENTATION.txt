PROJECT OVERVIEW
================================================================================
TreeStore is a mobile-first e-commerce application for purchasing trees and 
plants. Built with React, React Router, and Tailwind CSS, following modern 
web development best practices and industry-standard patterns.

Version: 1.0.0
Framework: React 18+ with Vite
Styling: Tailwind CSS with Dark Mode Support
State Management: React Hooks (useState, useEffect)
Routing: React Router v6
Icons: Lucide React


ARCHITECTURE OVERVIEW
================================================================================

1. COMPONENT STRUCTURE
   - Parent Component: MobileApp.jsx (Main container & state management)
   - Child Components: Individual page components
   - Shared Components: ProductCard, BottomNav, Header
   - Pattern: Container/Presentational Component Pattern

2. STATE MANAGEMENT
   - Centralized state in MobileApp.jsx
   - Props drilling for data flow
   - Callback functions for child-to-parent communication
   - Ready for Redux/Context API integration

3. ROUTING ARCHITECTURE
   - Client-side routing with React Router
   - Base path: /mobile/*
   - Protected routes for authenticated users
   - Nested routing support

DARK MODE IMPLEMENTATION
================================================================================

1. CONFIGURATION
   - Tailwind config: darkMode: 'class'
   - Main container adds 'dark' class when enabled
   - All components use dark: prefix for dark styles

2. USAGE PATTERN
   className={`bg-white dark:bg-gray-800 text-gray-900 dark:text-white`}

3. COMMON PATTERNS
   - Backgrounds: bg-white → dark:bg-gray-800
   - Text: text-gray-900 → dark:text-white
   - Secondary: text-gray-600 → dark:text-gray-400
   - Borders: border-gray-200 → dark:border-gray-700
   - Hover: hover:bg-gray-50 → dark:hover:bg-gray-700


BACKEND INTEGRATION GUIDE
================================================================================

1. API ENDPOINTS (Recommended Structure)
   
   Authentication:
   POST /api/auth/login
   POST /api/auth/signup
   POST /api/auth/forgot-password
   POST /api/auth/verify-otp
   POST /api/auth/reset-password
   
   User Profile:
   GET /api/user/profile
   PUT /api/user/profile
   POST /api/user/profile/image
   
   Addresses:
   GET /api/user/addresses
   POST /api/user/addresses
   PUT /api/user/addresses/:id
   DELETE /api/user/addresses/:id
   
   Products:
   GET /api/products
   GET /api/products/:id
   GET /api/products/search?q=
   GET /api/products/category/:category
   
   Cart:
   GET /api/cart
   POST /api/cart/add
   PUT /api/cart/update/:id
   DELETE /api/cart/remove/:id
   
   Orders:
   GET /api/orders
   GET /api/orders/:id
   POST /api/orders/create
   GET /api/orders/:id/track
   
   Wishlist:
   GET /api/wishlist
   POST /api/wishlist/add/:productId
   DELETE /api/wishlist/remove/:productId

2. INTEGRATION POINTS
   - Replace callback functions with API calls
   - Add loading states
   - Implement error handling
   - Add token management (localStorage/cookies)
   - Use axios or fetch for HTTP requests

3. EXAMPLE INTEGRATION
   ```javascript
   const handleLogin = async (credentials) => {
     try {
       const response = await fetch('/api/auth/login', {
         method: 'POST',
         headers: { 'Content-Type': 'application/json' },
         body: JSON.stringify(credentials)
       });
       const data = await response.json();
       setIsLoggedIn(true);
       setUserName(data.firstName);
       localStorage.setItem('token', data.token);
     } catch (error) {
       showToast('Login failed', 'error');
     }
   };
   ```


BEST PRACTICES
================================================================================

1. CODE ORGANIZATION
   - One component per file
   - Descriptive component names
   - Props destructuring
   - Consistent file naming (PascalCase)

2. STATE MANAGEMENT
   - Keep state as close to usage as possible
   - Lift state up when needed
   - Use callbacks for child-to-parent communication
   - Consider Context API for deeply nested props

3. PERFORMANCE
   - Use React.memo for expensive components
   - Implement lazy loading for routes
   - Optimize images (WebP format)
   - Minimize re-renders

4. ACCESSIBILITY
   - Semantic HTML elements
   - ARIA labels where needed
   - Keyboard navigation support
   - Sufficient color contrast

5. SECURITY
   - Never store sensitive data in localStorage
   - Validate all user inputs
   - Sanitize data before display
   - Use HTTPS for API calls
   - Implement CSRF protection

TROUBLESHOOTING
================================================================================

1. Dark Mode Not Working
   - Check Tailwind config has darkMode: 'class'
   - Verify 'dark' class is added to root container
   - Ensure components use dark: prefix

2. Routes Not Working
   - Verify React Router is properly configured
   - Check base path matches deployment path
   - Ensure BrowserRouter wraps the app

3. State Not Updating
   - Check if state is being mutated directly
   - Verify callback functions are passed correctly
   - Use React DevTools to inspect state

4. Images Not Loading
   - Check image URLs are correct
   - Verify CORS settings for external images
   - Use ImageWithFallback component
